Hermes Enterprise Stack Phase 1

Phase 1 provides the enterprise infrastructure foundation: modular Docker Compose V2 files, Traefik ingress, Docker socket proxy security, lifecycle scripts, environment-driven configuration, and operator documentation.

Ubuntu 24.04 LTS Docker Compose V2 Glass UI Vanilla JavaScript No hardcoded secrets Clean Architecture boundary Infrastructure only

Phase 1 Scope

Included

Compose modules, networks, Traefik ingress, Docker socket proxy, runtime directories, Make targets, lifecycle scripts, docs, and CI validation.

Not Included

No Hermes services. No Grafana, Prometheus, Loki, Redis, PostgreSQL, or other data-plane services.

Configuration

All runtime values are controlled through `.env`. The file is parsed as data and only accepts `HES_*` keys.

Architecture

HES separates infrastructure concerns from future application concerns. Compose modules describe resources, scripts operate lifecycle tasks, configuration is externalized, and runtime state stays outside source-controlled files.

Installation Guide

Install on Ubuntu 24.04 LTS with Docker Engine and Docker Compose V2 available. Start from the example environment file, review values, then run the installer.

Do not deploy with `example.com` values. Set `HES_ENVIRONMENT=production`, `HES_DOMAIN`, `HES_ADMIN_EMAIL`, exposed ports, and storage paths before production use.
Quick start
cp .env.example .env
make doctor
make validate
make install

Validation Guide

Validation checks Bash scripts, LF line endings, Docker availability, Docker Compose V2, and Compose configuration.

Validate project
make validate
Doctor

Use `make doctor` to check host readiness, writable runtime paths, Docker daemon access, and Compose configuration.

Repair

Use `make repair` to recreate missing `.env` and runtime directories. It can run before Docker is installed.

CI

The GitHub workflow runs validation on Ubuntu 24.04 and installs `shellcheck` before executing `make validate`.

Backup & Restore

Backups include `.env`, Compose files, config, TLS state, storage, and data. Archives are written with owner-only permissions because `.env` is included.

Create backup
make backup
Restore with env
HES_RESTORE_ARCHIVE=backup/hes-backup-20260709T000000Z.tar.gz make restore
Restore directly
./scripts/restore.sh backup/hes-backup-20260709T000000Z.tar.gz

Security Notes

No Direct Docker Socket

Traefik talks to the Docker socket proxy instead of mounting `/var/run/docker.sock` directly.

Container Hardening

Services use `no-new-privileges`, dropped capabilities, read-only filesystems where supported, and process limits.

Managed Cleanup

Runtime directories use `.hes-managed` markers. Cleanup refuses unmanaged directories.
