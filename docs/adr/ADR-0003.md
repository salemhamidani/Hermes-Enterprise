# ADR-0003: Do Not Mount Docker Socket Directly into Traefik

| Field | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-07-09 |
| Supersedes | None |
| Superseded by | None |

## Context

Traefik needs Docker metadata for service discovery, but mounting `/var/run/docker.sock` directly exposes a powerful host control surface.

## Decision

Use `tecnativa/docker-socket-proxy` between Traefik and the Docker API. The proxy exposes only the read-only metadata endpoints required for discovery.

## Consequences

- Traefik never receives the raw Docker socket.
- Docker API permissions remain explicit and reviewable.
- Any future discovery expansion must revisit proxy permissions before implementation.
