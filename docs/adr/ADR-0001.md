# ADR-0001: Use Modular Docker Compose Files

| Field | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-07-09 |
| Supersedes | None |
| Superseded by | None |

## Context

HES is expected to grow beyond 50 Docker services over time. Phase 1 starts with infrastructure only, but the project must already behave like a maintainable enterprise platform.

## Decision

Use modular Compose files in `compose/`, with launcher scripts loading the modules in a deterministic order. `compose/compose.yml` remains as a backward-compatible include-based entrypoint.

## Consequences

- Future services are added as dedicated Compose modules.
- Review scope stays smaller and easier to own.
- Production automation should prefer `scripts/compose-*.sh` launchers for portability.
