# ADR-0002: Use Traefik as the Ingress Layer

| Field | Value |
| --- | --- |
| Status | Accepted |
| Date | 2026-07-09 |
| Supersedes | None |
| Superseded by | None |

## Context

HES needs a reverse proxy and ingress layer that fits Docker Compose V2 and can scale with future service growth.

## Decision

Use Traefik as the shared ingress layer for HTTP and HTTPS entrypoints and future service routing. Phase 1 keeps this as infrastructure preparation only.

## Consequences

- Future public services should route through Traefik.
- Direct host port publishing remains exceptional.
- Traefik configuration must remain conservative until later implementation sprints.
