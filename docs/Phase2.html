Sprint 2 - Version 1.1.0

Security Foundation

Production security foundation for HES infrastructure only. No Hermes Agent, Dashboard, WebUI, monitoring stack, database, or application route is implemented in this sprint.

Infrastructure Only

Network, Traefik, TLS, logs, secrets preparation, validation, and repair.

Production Traefik

HTTPS, ACME HTTP challenge, security middleware, structured logs, ping, and metrics preparation.

Defense in Depth

Network segmentation, socket proxy isolation, container hardening, and safe secret handling.

Traefik Foundation

Traefik is configured through `compose/traefik.yml` with production flags. Reference static config lives under `config/traefik/` for future migration.

make repair
make validate
make install
make status

TLS and ACME

Let's Encrypt HTTP challenge is configured through Traefik. Use the staging CA before production exposure to avoid rate limits.

HES_TRAEFIK_ACME_CA_SERVER=https://acme-staging-v02.api.letsencrypt.org/directory

Troubleshooting

SymptomAction
ACME failsConfirm DNS, port 80 reachability, and use staging CA first.
Permission error on ACMERun `make repair` to restore `ssl/letsencrypt/acme.json` permissions.
Compose network failureCheck `HES_*_NETWORK` variables and run `make validate`.
No route publishedExpected in Sprint 2; Hermes routing is out of scope.
